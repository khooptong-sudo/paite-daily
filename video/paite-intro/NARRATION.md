# Paite Daily — narration script

Four segments. One segment for each scene. The actor speaks in a calm,
friendly register, at a steady pace.

| # | Scene | Text | Available time |
| --- | --- | --- | --- |
| 1 | Title | Paite Daily. One sentence a day, in Paite. | 0.4–3.9 s |
| 2 | What it is | Read a simple English sentence. Write it in Paite. | 4.5–8.2 s |
| 3 | How to use it | Read it. Type it in Paite. Then tap Send. | 8.8–12.9 s |
| 4 | What happens next | Reviewers check each answer. The data is open and free. | 13.5–17.0 s |

The address stays on screen and is not read aloud.
